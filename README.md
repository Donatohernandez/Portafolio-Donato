# Donato Hernández — Portafolio México

Portafolio profesional en español, enfocado en el mercado mexicano. Desarrollado con **Next.js 16**, **TypeScript**, **Tailwind CSS** y **Framer Motion**.

**Sitio:** [mx.donatohernandez.dev](https://mx.donatohernandez.dev)

## Ejecutar localmente
